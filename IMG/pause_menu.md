# Pause menu artwork

`pause_book.png` and `pause_resume.png` were prepared with the built-in image generation tool from the user's `Modo Tranquilo_ Uma Pausa para Ler.png` reference. The menu title, resume button, mode choices and explanation are live controls. The initial menu reuses the same paper assets with its own live layout in `scripts/start_book.gd`.

## Book prompt

> Use case: precise-object-edit. Asset type: transparent background artwork for a working Godot pause menu. Edit target: user reference of an open book pause menu. Isolate the entire open book, brown leather cover, stacked page edges, left leather tabs, central binding and hanging amber bookmark. Remove the dark surrounding background to true transparent alpha. Remove ALL text, titles, letters, button strip, toggle switch, metal clasp in the middle, book icon separator and interface content from both pages. Reconstruct blank cream parchment where removed. Preserve the full silhouette, near front-on top-down composition, curled worn corners, warm pale paper fibers, thin sepia ink outlines and faint horizontal ruling in the lower two thirds of the pages. Both pages blank and broad, with only a narrow gentle natural center fold and no dark distracting stains. Book width to height about 1.4:1, tightly framed with only a small transparent margin around the full silhouette including the bookmark. Match reference hand-painted fantasy illustration closely. Output one isolated blank open-book asset, no words, no UI controls, no other objects.

## Resume button prompt

> Use case: precise-object-edit. Asset type: transparent parchment button sprite for a functional Godot menu. Edit target: isolate ONLY the large gold parchment RETOMAR button strip from the supplied open-book reference. Remove every letter so the center is entirely blank. Preserve the long horizontal rectangular strip, hand-inked dark brown uneven outline, warm amber paper, frayed/torn irregular edges, small dog-eared folds at corners, creases and subtle shadow. True transparent alpha outside the paper. Wide low silhouette, approximately 5.8:1 width to height, tight frame around the strip. No surrounding book, no background, no pins, no symbols, no lettering or text at all. One blank amber parchment button sprite only.
